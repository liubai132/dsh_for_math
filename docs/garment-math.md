# 用数学做一条百褶裙：知识、流程与代码结构

这份文档记录 `plugin/math-atelier` 里扩展三（PBD 布料）的设计。目的是把「数学 → 代码 → 服装」这条路固化下来，以后做别的服装可以直接套。

---

## 1. 从布料工艺到几何参数

### 1.1 刀褶是 3:1，不是 2:1

一个刀褶（knife pleat）在截面上分三段：

```
        可见面 w
   ┌──────────────┐
   │              │
───┘              └───┐
   ┌──────────────┐   │   回折层 w（折回，藏在下面）
───┘              └───┤
   ┌──────────────┐   │   搭叠层 w（延伸到下一褶下面，被压住）
   └──────────────┘   │
                    折边
```

所以一个褶周期要吃掉 `3w` 的布，整圈布料周长 ≈ 3 × 腰围（制服裙常用 2.5–3 倍）。

只做「面 + 回折」是 2:1，折边只有两层厚，看起来不像压住的褶。

### 1.2 几何参数

| 参数 | 含义 | 当前值 |
|---|---|---|
| `pleats` | 褶数 | 18 |
| `columnsPerPleat` | 每褶的网格列数（3 层 × 3 列） | 9 |
| `rows` | 竖向行数 | 20 |
| `waistRadius` | 裙身基准半径 | 0.215 |
| `bandRadius` | 腰头半径（比裙身收一点） | 0.2 |
| `bandRows` | 腰头占的行数（固定不参与模拟） | 2 |
| `flare` | 裙身向外扩的量 | 0.09 |
| `pleatDepth` | 褶的鼓出高度 | 0.075 |
| `height` | 裙长基准 | 0.92 |

### 1.3 半径曲线

```js
open   = clamp((u − 0.05) / 0.95)        // 0 在腰头，1 在下摆
bodyR  = waistRadius + flare · open^1.15  // A 字外扩
depth  = pleatDepth · open^1.05           // 褶越往下越张开

R_FACE_ROOT  = bodyR                      // 褶根贴身体
R_FACE_CREST = bodyR + depth              // 折痕最外
R_BACK       = bodyR − 0.006 − 0.004·open // 回折层
R_OVER       = bodyR − 0.012 − 0.008·open // 搭叠层（最内）
```

外片面是**从褶根到折痕的斜面**，不是等半径的圆弧——否则轮廓是光滑圆台，下摆没有锯齿。

### 1.4 角度映射

每褶 9 列，按层分配：

```
f = 0..2   外面片：θ 从褶根走到折痕，r 从 ROOT 升到 CREST
f = 3..5   回折层：θ 从折痕折回褶根，r = R_BACK
f = 6..8   搭叠层：θ 再走一遍，r = R_OVER
```

腰头是正圆直筒（`ex = ez = 1`），从第 `bandRows` 行开始才有褶。

## 2. 网格生成

- 22 行 × 162 列（18 褶 × 9 列）= 3240 个粒子
- 顶部 `bandRows` 行 `invMass = 0`（固定成刚性腰环）
- 腰头与裙身**错开半个褶**，暗示腰头是单独缝上去的一片布

```js
for (let j = 0; j < rows; j++) {
  const u = j / (rows - 1)
  const y = waistY - u * height
  const open = clamp((u - 0.05) / 0.95)
  const bodyR = ...
  for (let i = 0; i < cols; i++) {
    const k = floor(i / columnsPerPleat)
    const f = i - k * columnsPerPleat
    // 按 f 落层，得到 theta 和 r
    particles.push({ x: cos(theta) * r, y, z: sin(theta) * r, invMass: j < bandRows ? 0 : 1 })
  }
}
```

## 3. 物理：Position-Based Dynamics

### 3.1 约束

| 类型 | 连接 | 作用 |
|---|---|---|
| 结构 | 相邻列 / 相邻行 | 保持布料周长与长度 |
| 剪切 | 对角线 | 防止网格塌成菱形 |
| 弯曲 | 隔一列 / 隔一行 | 保持褶的形状 |

静止长度**直接取自初始网格**——褶是烘进静止形状里的，解算不会把它抹平。

### 3.2 每步循环

```
1. 速度积分：v += g·dt，x += v·dt（记录 px, py, pz）
2. for iter in 0..3:
     a. 所有距离约束投影（按逆质量分配）
     b. 身体碰撞（躯干/胯/腿三段圆柱）
     c. 层间排序：外片 > 回折 > 搭叠，只沿径向推
3. 速度反推：v = (x − px) / dt × damping
4. 限位与形状记忆
```

### 3.3 几个关键设计

- **层间约束只沿径向**：曾经用「两点连线方向」推，布料翻折时方向不稳定，会把裙子锁成死结；改成比较半径、沿径向推之后就不会卡住。
- **位移上限**：每个粒子离静止位置不超过 `0.3`，保证任何拖拽都能回到原形。
- **形状记忆很弱**（0.004）：只防拉散，形状交给重力决定。
- **腰头固定**：`invMass = 0`，抓取时跳过这些粒子。

## 4. 渲染

三条路径，同一份粒子数据：

| 路径 | 遮挡 | 光照 | 格纹 |
|---|---|---|---|
| Canvas 2D | 画家排序 | 逐面 Lambert + AO | 逐面平涂（粗） |
| WebGL | 深度缓冲 | 逐三角形法线 + 高光 + AO | 逐像素（细） |
| WebGPU | 深度缓冲 | 同上，法线用导数 | 逐像素（细） |

### 4.1 法线

- 2D / WebGL / WebGPU 都用 `cross(dFdx(world), dFdy(world))` 求几何法线
- 折痕两侧绕序相反，用 `dot(n, 径向) < 0` 把法线统一翻到朝外
- WebGL 需要先 `gl.getExtension('OES_standard_derivatives')` 才能用导数

### 4.2 AO

```
ao = clamp(该点半径 / 本行最大半径, 0.3, 1)
```

褶谷小、褶峰大，褶谷自然变暗。

### 4.3 格纹

按布料坐标 `(列, 行)` 采样，不是屏幕坐标，所以格纹跟着褶一起折：

```
u = ((列 + 2) / 总列数) × 18    // 相位错开 1/3 格，避免线压在折痕上
v = (行 / 总行数) × 6
```

- 细线：`min(fract(u), 1−fract(u)) < 0.075`
- 宽条：`0.42 < fract(u) < 0.58`

### 4.4 光照

- 固定世界光：`normalize(−0.45, 0.72, −0.53)`，从左上前方照来
- 环境光很低（0.12，带冷色），漫反射 1.7——黑布在阴影里接近黑，不是灰
- 高光窄而柔（指数 28、强度 0.22），微法线扰动 0.1：太多会碎成白点

## 5. 代码结构

`client.js` 里布料相关部分：

```
GARMENT_SPEC            ← 服装参数（褶数、层数、半径、裙长等）
buildCloth(lengthScale) ← 生成粒子与约束
stepCloth(sim, dt, breeze, grab)  ← PBD 一步
collideCloth(particles) ← 身体碰撞
createClothGL(canvas)   ← WebGL 渲染器
createClothGPU(canvas)  ← WebGPU 渲染器
ClothDemo()             ← React 组件：状态、交互、三种后端切换
```

数据流：

```
GARMENT_SPEC → buildCloth → { particles, constraints }
                                   │
                     stepCloth ←───┘（每帧 1/120 秒 × 2 个子步）
                                   │
                     renderer（2D / GL / GPU）
```

## 6. 如何加一件新服装

1. **只改参数**：调 `GARMENT_SPEC` 的 `pleats` / `rows` / `flare` / `pleatDepth` / `height`
2. **换褶型**：改 `buildCloth` 里的 `f` 分段（例如箱褶做成 `f=0..1` 面、`f=2..3` 折回来，两侧对称）
3. **新服装**：照 `buildCloth` 写一个新函数，返回同样的 `{ particles, constraints }`，`stepCloth` 和三个渲染器都不用改
4. **真实布料**：把 `MAX_FRAME` 之类改成按米制单位，重力取 9.8

---

## 7. 已知限制

- 没有自碰撞：褶与褶之间可能穿插（只做了同褶内的层间排序）
- 没有布料厚度与摩擦，层间靠强制排序
- 求解在 CPU 上，3240 粒子大约 30fps；再往上需要把 PBD 搬进 compute shader
- 腰头是同一张网格的顶部两排，不是独立的缝合片

## 8. 折叠的严格模型（fold.py）

前面第 1 节说「3:1」，但真正的折叠不是随手摆三条边，而是一个**等距映射**：布折前折后的长度不变。

### 8.1 约束

一个刀褶在截面上有三段布：可见面 w、回折层 w、搭叠层 w。折成锯齿后，三段变成三条弦，并且：

- 三条弦的长度都等于 w（布长守恒）
- 三条弦的张角之和等于一个褶的角度 Δ = 2π/N（围成一圈闭合）

三段等长 ⇒ 张角均分 α = Δ/3，弦长由半径差 d 决定：

    chord(R + d, R, α) = w

解出 d 就是**折痕深度**。它由「布长要塞进一个褶的角度里」决定，不是手动指定的。

### 8.2 数值

| 褶数 N | 可见宽度 w | 折痕深度 d | 布长/可见宽度 |
|---|---|---|---|
| 12 | 0.113 | 0.103 | 3.0 |
| 18 | 0.075 | 0.069 | 3.0 |
| 24 | 0.056 | 0.052 | 3.0 |

褶越密，同样布长需要塞进更小的角度，折痕更深。

### 8.3 张力

布长是固定的。如果腰围要求更小的 R，同一个张角里塞不下 w，折痕只能撑开——这是「张力」的来源。

    fit_radius(N, fabric_length)：给定布长反推最小可见半径

例：18 褶、布长 2.0 → 最小半径 0.318；如果强行做到 0.215，折痕会被迫更深（或者布料被拉伸，也就是现在的 PBD 在干的事）。

### 8.4 接口

    POST /api/fold/skirt  { pleats, radius, layers }
    → { depth, segment_angle, segment_chord, fabric_length, fabric_ratio }
